## Overview
This project's Obsidian vault root is the repository root (`5 agents/`). The `.obsidian/` config folder sits there, making every file in the repo part of the vault. Notes and session logs live under `vault/` sub-folders as per the `obsidian-vault-workflow` skill convention. The `obsidian-vault-workflow` skill is mandatory on every session start.
